# 🚀 Repositorio de PoCs de IA Generativa

Este repositorio centraliza el conocimiento, los prompts y la arquitectura de las Pruebas de Concepto (PoCs) desarrolladas para el departamento. El objetivo es facilitar la reutilización de lógica de negocio y configuraciones de LLMs en futuros proyectos.
